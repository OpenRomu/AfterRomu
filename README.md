# RomuStrike 140 Source Code

This repository contains the source code for version 140 of the RomuStrike game.
The full source code is included, with minimal modifications.

To run the game, you will need to obtain the game data from a version 140
installation, which can be found
[here](https://archive.org/details/romustrike_140).

**provide any support or warranty for this source code. It is provided "as is"**
**without any guarantees or liability. Users are responsible for any use or**
**modification of the code.**

## Authorization

The release of this source code has been authorized by one of the game's
developers.

## Included Files

This release includes the full source code, with the following exceptions:
- Trash files and data files have been removed.
- The only exceptions are ".bak" and ".tmp" files, which have been preserved
  for historical purposes.
- Some internal API keys has been removed such as "Gmagic_key" and
  xmlmessaging.cpp:101.
